Independent Flutter hybrid assistant project.

## Status
Repository initialized. Flutter source has not yet been pushed; web deployment is not live.

The source archive is available in the ChatGPT conversation as `PULSE_AI_Flutter_Web_Ready_v0.2.zip`. Upload the **contents of its `pulse_ai/` directory** to the repository root (not the ZIP itself) to enable the included GitHub Actions Flutter build workflow.

## Security
The public Flutter Web preview must not embed API keys. Cloud chat requires an authenticated server-side proxy.
